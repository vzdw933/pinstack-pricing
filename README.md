## 它实际能干什么，什么人用得上

找东西靠搜索框，不是一条条往下滚。常用的片段可以 Pin 住，单独放在一个视图里，不用每次都翻。预览这块支持文本、链接、图像和颜色，选之前能看清是什么。它还提供一些整理动作，比如清掉从网页复制来的富文本格式，图片旋转或另存，以及在资源管理器里定位文件。复制过的文件夹和多个文件也能重复调用，这一点系统自带的剪贴板做不到。

真正会天天用上的场景，是那些“同一段内容要贴到好几个地方”的活：客服回模板话术、把表格里的数据分几次填进系统、写稿时反复引用同一段引文、改代码时在几个文件之间搬同一段配置。这类动作一天做几十次，有个能搜的历史列表，省下的是零碎但真实的时间。
